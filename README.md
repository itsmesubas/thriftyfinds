## 🧪 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/thrifty-finds.git
   ```

2. Move project to your **XAMPP** or **WAMP** `htdocs` folder.

3. Import the SQL file into phpMyAdmin.

4. Configure your database in `config/db.php`.

5. Run the project:

   * Open browser → **[http://localhost/thrifty-finds](http://localhost/thrifty-finds)**
